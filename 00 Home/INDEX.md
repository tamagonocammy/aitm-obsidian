# INDEX: map of the vault for assistants

Written for ChatGPT and any assistant that reads this vault, mainly through the GitHub backup. Approved by Millie on 2026-11-18. It describes where things are; it is not a source of canon.

## Read in this order
1. `60 Meta/_admin/CHECKPOINT.md` (where the last writer stopped; confirm a single writer before editing)
2. `00 Home/Canon Rules.md`
3. This INDEX
4. `00 Home/Rulings Log.md` (decisions already made; they win over older text)
5. `00 Home/Open Questions.md` (things waiting on Millie; not canon)
6. Only the notes the question needs. Do not read the whole vault.

## Folder map
- `00 Home`: Home, Canon Rules, Rulings Log, Open Questions, How This Vault Works, and this INDEX.
- `10 Characters`: one note per person, named by the Na'vi name alone. Facts are in the properties at the top (navi_name, source_name, source_series, family, groups, role, ikran, birthday, age, gender, pronouns, transition, canon).
- `20 Groups`: families, factions, and `Relationship Lore`.
- `30 World`: places, customs, technology. `Worldbuilding Reference` is the long overview.
- `40 Story`: `Timeline`, then `Arcs`, `Eras`, `Scenes`.
- `50 Language`: Na'vi references (case forms, family terms, proverbs, accent, Reef Na'vi, name audit).
- `60 Meta`: notes about the project (Vault Design, Canon Audit, MBTI Reference, AU Analysis, MyMuji Season Plan, Working Reference) and `_admin` (CHECKPOINT, Operations Protocol, Open Questions Index, tasks.json).
- `_inbox`: new ideas as dated notes. They are proposals, not canon, until ruled in the Rulings Log.
- `_templates`: Character, Group, Place, Arc, Scene.
- `99 Archive`: the original files from before the migration (2026-11-11). Old text; never edit; where it disagrees with the vault, the vault wins.
- `90 Sources`: PDFs and backup tarballs. Exists only on Millie's computer, not in GitHub.

## Conventions that matter
- `canon: confirmed` is settled, `tentative` is not settled, `discarded` is an old idea kept on purpose.
- An empty property means "not established." Never read an empty gender or transition field as cis, and never fill it in.
- A link in `family` or `groups` is the real placement. Only some characters have a family set; do not guess one.
- Use the Na'vi name in prose. The anime name is in `source_name`.
- `Home.md` shows tables through `.base` files, which are live queries only Obsidian can run. Use the roster below instead.
- Na'vi words and names: check Reykunyu. Nothing is canon until Millie confirms it.
